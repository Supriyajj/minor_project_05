# 📊 Sales Performance Analysis | Excel Minor Project

## 📌 Project Overview

This project is an Excel-based data analysis project focused on analyzing sales, customers, products, sales representatives, and performance targets.

The project uses multiple related datasets and applies different Excel techniques to clean data, perform lookups, calculate business metrics, create pivot tables, and solve advanced analytical problems.

The analysis is divided into five major sections:

* Lookup Functions
* Data Cleaning & Quality Diagnostics
* Conditional Aggregation
* Pivot Tables
* Advanced Excel Analysis

---

# 📂 Dataset Structure

The project contains the following datasets:

### 1. Orders

The main transactional dataset containing order-level information.

Key columns include:

* `order_id`
* `order_date`
* `customer_id`
* `product_id`
* `sales_rep_id`
* `quantity`
* `unit_price`
* `discount_pct`
* `final_amount`
* `payment_status`
* `ship_city`

### 2. Customers

Contains customer information such as:

* Customer ID
* Customer Name
* Age
* City
* Segment
* Signup Date

### 3. Products

Contains product-related information:

* Product ID
* Product Name
* Category
* Unit Cost
* Unit Price
* Active Status

### 4. Sales Representatives

Contains information about the sales team:

* Rep ID
* Rep Name
* Region
* Hire Date
* Team Lead ID

### 5. Targets

Contains monthly sales targets for each sales representative.

# 📈 3. Conditional Aggregation

Conditional formulas were used to answer business-related questions.

Functions and techniques include:

* `SUMIFS`
* `COUNTIFS`
* `AVERAGEIFS`
* Multiple-condition analysis
* Date-based filtering
* Category and customer segment analysis

Some examples of the analysis include:

* Total revenue for Mumbai during Q3 2024
* Number of completed orders with discounts above 15%
* Average order value for Electronics products purchased by Corporate customers
* Revenue generated by the top sales representatives
* Performance comparison between actual sales and targets

---

# 📊 4. Pivot Table Analysis

Pivot Tables were used to summarize and analyze sales performance from different perspectives.

Analysis included:

* Sales region vs product category
* Monthly revenue by sales representative
* Percentage contribution of product categories
* Quarterly revenue analysis
* Profit margin analysis

Pivot Tables helped transform large amounts of transactional data into meaningful business insights.

---

# 🚀 5. Advanced Excel Analysis

Advanced Excel techniques were used to perform deeper analysis.

Techniques include:

* `RANK.EQ`
* Running and cumulative totals
* `LARGE`
* `INDEX/MATCH`
* `TEXTJOIN`
* Multi-condition analysis
* Top-N analysis

The advanced analysis answered questions such as:

* Which sales representative ranked #7 by total revenue?
* What was the cumulative revenue up to August 2024?
* Which product generated the second-highest revenue in the West region?
* Who were the top 5 sales representatives?
* What was the highest order value for a specific city and product category?
